# 本人个人主页与资料编辑

2026-10-20

沿用他人主页的校园封面、圆形头像、简介、关系统计和青绿色按钮。复用同一 `CommunityProfile`，本人主页保留校园功能；“编辑资料”和“我的笔记”各出现一次，取消旧的头像旁资料跳转、单独封面按钮和下方“笔记与草稿”重复入口。

编辑页集中更换头像、背景、昵称和简介。背景有六张现有校园预设，支持自选 JPG、PNG、WebP；头像和背景单个文件均不超过 5 MB，选择后裁切、压缩、预览，点击保存才写入。校园身份信息折叠保留，学校邮箱核验沿用原入口。主页面继续提供活动、校园组织、队伍、综合收藏、日历、课表、校友交流、身份认证、通知和设置。

资料由原 `profile.save` 一次保存，新增 cover 字段；缺失时兼容旧背景偏好。旧背景偏好操作同步更新已有 cover。本人和公开社区页读取同一份资料，关闭资料预览后，其他学生看不到本人自选头像、背景、昵称与简介。

本地验证：

- 前后端类型检查和范围 ESLint 通过；社区、背景偏好与侧栏偏好三个定向测试文件，18 项测试连续三轮通过。
- 使用真实文件选择器选取项目校园图片，完成头像和背景压缩预览、简介修改、保存与刷新读回；取消编辑保留原保存值。非图片文件被拒绝，原头像和输入保留。另验证预设背景保存与恢复默认头像。
- 新增后端测试覆盖自选背景保存、拒绝外部 URL、失败后原资料不变、旧偏好兼容、保留简介，以及关闭预览后的背景隐私投影。
- 浏览器确认“我的笔记”进入本人社区页，资料保持一致，返回入口回到“我的”。原校园入口使用原路由和数据。
- 检查 390×844、1280×900，以及 320×740 英文深色模式。内容宽分别不超过视口；320 视口内容宽 305，1280 视口内容宽 1265。修正“更换头像”的旧英文翻译，补充新界面的翻译。最后恢复系统语言、系统主题与自然视口，打开中文本人主页。
- 一轮主 Agent 视觉自检，无独立评审。交互反馈沿用既有按钮、图片预览与模态窗口；没有新增持续动效。未验证真实手机键盘、200%浏览器缩放、弱网和生产环境。

预览数据属于本地模拟账号。文件上传验证临时使用项目校园照片，最后恢复默认头像和原简介，预览使用湖畔校园预设。截图包含上传保存状态与最终状态，均不代表真实用户资料。
