# 独立视觉评审与处理

按 Oil UI 的“存量已有界面润色评审”进行 1 轮，不打分。评审者使用隔离上下文，只读当前截图及任务约束，未读取制作代码。查看了 17 张代表截图，包括三端、账号页和校园长页；主 Agent 另外以原始手机截图拼版逐页检查了全部 45 个入口。

保留：校园照片、拱角窗口、深青文字与米白画布的共同主线。

| 评审意见 | 处理与复查 |
| --- | --- |
| 手机课表浮层遮住快捷入口，社区双悬浮按钮挤在正文旁 | 课表入口移至原页面顶栏；社区使用原页面发布按钮，隐藏重复悬浮发布入口。`verify_states.py` 在 320、390、720 宽度检查工具按钮边界，并验证发布弹窗。 |
| 登录照片上的重复英文被弧形裁切 | 去掉该装饰标记；手机标题恢复语义断行，查看登录手机与桌面截图。 |
| 学生交流页教师姓名出现在首屏过低位置 | 手机压缩重复照片区，隐藏重复宣传说明；当前首屏可辨认教师姓名及既有方向。 |
| 教师预约卡片纵向空耗 | 收紧段落间距和卡片行距；保留时间结束不代表到场的说明、处理记录及原操作按钮。 |
| 社区亮蓝色主操作及筛选不协调 | 采用既有蓝灰主操作、灰绿选中态，统一默认头像背景；查看社区截图。 |
