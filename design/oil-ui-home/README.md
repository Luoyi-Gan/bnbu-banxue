## 内容与约束

- 本轮是静态视觉候选；选择方向后再接入现有 React 页面、后端读数与交互。
- `round-01/content.json` 是三套方案共同的模拟内容来源。画面保留“本地模拟”标识；数据不代表真实课程、活动、通知或人员。
- 体育未知进度显示“— / 待同步”，不以零进度代替未知，不生成运动、学时或审核事实。
- 已保存课表不表示实际上课；活动参与标记不表示正式报名、占用名额或到场。
- 手机导航使用当前项目的首页、发现、校园、打卡、我的。
- 复用 `src/assets/campus/` 校园照片及 `public/fonts/` 的霞鹜文楷、MiSans；字体许可保留在原资源目录。
- 三方案正文、数字和导航使用 MiSans，标题使用文楷。由于用户要求沿用字体，本轮通过照片比例、阅读顺序和空间组织产生差异。
