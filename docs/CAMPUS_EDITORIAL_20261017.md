## 组件规范与分阶段实施
1. 基础层：品牌文楷、栏目宋体、正文与数字分工；按钮44px基本触达区域；3px焦点轮廓；无默认阴影与背景模糊；降低动态效果偏好和强制颜色模式兼容。
2. 活动：摄影封面、宋体标题、细线分区、低饱和状态标签；桌面留白、移动端单列；原有筛选、收藏、详情入口沿用。
3. 社区：两列 CSS columns 图文瀑布流，卡片禁止跨列分割；照片与文字保持可打开，互动按原逻辑；DOM/键盘顺序先第一列再第二列。
4. Coffee Chat：人物身份、研究方向、图片与箭头形成清晰层级；桌面双列、手机单列。现有数据缺少真实人物肖像，继续使用既有图片与姓名头像，不伪造人物照片。
5. 体育：苔绿细环、Inter 指标、灰蓝核心操作、自然校园摄影；照片上的文字使用实色底提高可读性。
6. 首页、校园、个人页及共用导航、表单、弹窗继承同一视觉变量，清理彩色面板与高强度装饰。

## 可访问性核对
