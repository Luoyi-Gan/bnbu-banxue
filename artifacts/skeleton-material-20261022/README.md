# 骨架材质与动效参数

- 活动、社区和组织首次读取使用共用 LoadingSwap；与实际列表共用列间距及容器宽度断点，封面沿用 discovery-cover 的材质与场景圆角，文字条保留标题和辅助信息层级。首页下一项安排仍使用原课程卡片外壳、阴影和圆角，内部占位对应标题与两列时间地点信息。
- 占位使用暖白/浅青灰基底及低透明度微光，取消原明暗脉冲。活动、社区、组织图片加载时使用相同材质，图片到达后通过透明度替换；图片失败继续显示原错误/文字封面。组织图片来源改变时重置加载状态。
- 骨架退出约180ms，与真实卡片同一网格单元衔接，完成后移除占位节点；沿用现有卡片错峰进入。减少动态效果时取消微光、图片淡入及骨架退出时长。
- motionTokens.ts 提供按压120ms、选中180ms、卡片展开300ms/返回220ms、弹窗280ms、列表240ms/错峰36ms、状态确认280ms/取消220ms、内容替换180ms和面板弹簧参数。共享展开、列表、状态图标和面板回弹已引用；CSS按压/选中/替换/微光使用命名变量。滚动保持原位置绑定机制。
- 本地组件验证页 preview.html 直接导入实际 LoadingSwap 与样式，查看加载、内容、减少动态三个状态；截图 loading.png/loaded.png，DOM记录 checks.json。微光实际为 material-skeleton-flow，减少动态后 animationName=none；替换后占位为0、aria-busy=false。验证切换后恢复原本关闭的减少动态偏好。
- 活动实际页6张卡、组织4张、社区6张正常显示且读取结束；活动真实封面在发现页上下文圆角10px，骨架同样继承10px；组件独立验证页默认12px。首页课程卡保持原白色基底与原圆角。活动截图 activities.png。
- 本机接口响应很快，加载过程的可控取证来自共用组件验证页；未模拟真实慢网络或物理手机。局部自查通过，类型检查、ESLint与相关动效回归11项通过。
