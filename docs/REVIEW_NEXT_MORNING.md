## 如何恢复

可直接在本对话说“开机了，启动验收”，由助手启动已有本地测试库，不重建或覆盖数据。手动启动：在仓库根目录PowerShell执行以下内容，Node 24需在PATH中：

```powershell
$env:BNBU_DATABASE=(Join-Path (Get-Location) 'data/browser-acceptance.sqlite')
$env:BNBU_LOCAL_OUTBOX='1'
$env:BNBU_SCHOOL_EMAIL_DOMAINS='example.test'
node scripts/local.mjs
```

打开 http://127.0.0.1:4174/v2/login ，登录后进入 /workspace。当前旧版/v2的其他演示界面不等于共享后端验收入口。

总管理员测试凭据位于data/browser-acceptance-accounts.json（roles包含superadmin的条目）。独立分管理员凭据位于data/admin-acceptance-account.json，登录类型选择“独立分管理员账号”。密码不写入此文档、不推送Git。两者只属于本地测试，example.test不是学校邮箱。
