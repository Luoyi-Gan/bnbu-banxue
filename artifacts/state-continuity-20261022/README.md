# 连续状态转换验证

- 沿用现有颜色和按钮，状态变化时衔接轻量压缩、填充和回弹。活动收藏/点赞读取原有状态，初次加载不播放确认动画；更新后的激活状态播放 280ms 压缩回弹，取消播放 220ms 收起，SVG 填充在 160ms 内过渡。保存期间禁用重复操作并提供 aria-busy。
- 动画可中断，快速反向时取消旧动画，旧完成回调不会清掉新动画；减少动态效果时跳过图标运动。键盘、按钮文案与 aria-pressed 继续表达当前真实状态。
- 日期、预约时段、发现和通知筛选使用约 180ms 背景与颜色过渡。通知未读点保留 DOM，通过透明度和缩放淡出，已读时从辅助技术中隐藏，避免瞬间删除与文字位移。
- Coffee Chat 提交按钮增加保存中文案，提交时清掉上一条反馈；原 mutate 成功后才显示勾选确认，失败使用错误提示及 alert。成功反馈轻量进入；没有创建或取消预约作为本次取证数据，提交结果分支未完成浏览器端到端验收。
