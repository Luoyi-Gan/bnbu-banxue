# 校园 AI 聊天界面 · 2026-10-22

方向：温和底色、低对比边界、正文优先、固定输入锚点。桌面阅读内容约732px；手机正文15px、行高1.8。沿用会同里MiSans、校园品牌色与奶蛙形象，更换形象和自选上传保留。

参考：用户提供的178.7秒视频，重点采用边界透明度、克制字重、轻淡入和连续状态；视频接触表在.runtime/ai-chat-design/video-contact.jpg。没有将演示中的“已思考N秒”作为真实过程。

| 任务 | 行为与验收 |
| --- | --- |
| 开始 | 安静的欢迎页、4个问题建议，仅填入草稿，不直接产生模型调用 |
| 输入 | 多行自增高、最多500字、输入法不误发送、发送按钮状态明确 |
| 请求 | 即时显示本次问题和真实等待状态，重复提交禁用，无假搜索进度 |
| 失败 | 问题保留、错误就近、重试沿用标识，失败不伪造回答 |
| 阅读 | 正文、标题、列表、表格、引用、代码与安全链接；可复制及追问 |
| 来源 | 内联引用定位来源卡片；课表卡读取真实工作区当前已选课程 |
| 追问 | 显式引用本人指定回答；当前资料重新检索核对；最多6000字符语境 |
| 历史 | 本人已有问答、搜索、跳转；桌面可折叠，手机以原有Modal打开 |
| 滚动 | 向上阅读保留位置；新内容提供最新入口；底部才自动跟随 |
| 设备 | 430×932、320×740、1440×1000、深色、大字、减少动态本地浏览器检查 |

三处动效：输入焦点边框/阴影180ms；消息淡入与4px入场220ms；历史栏布局260ms。均可被新状态自然替换，减少动态关闭过渡。状态呼吸仅在实际请求期间显示。

证据：.runtime/ai-chat-design/verification.json与同目录截图。延迟、失败、长会话及富文本以浏览器拦截的合成回答测试，不落入后端；全局本地模拟数据说明保留。实际模型验证使用独立合成学生，1次DeepSeek追问成功，返回“天文协会属于学术类社团[1]”，有当前社团来源。

接口目前整段返回，不包含token流或工具阶段事件；前端55秒超时不表示可撤销服务器已进行的计费请求。已保存答案的幂等重试继续复用。没有新增附件、语音、模型切换或自动执行业务操作。

未验收：真实手机软键盘、屏幕阅读器与生产环境；可视视口适配仅完成本地浏览器布局验证。
