# 会同里产品宣传页

日期：2026-10-20。入口：`/` 与 `/intro`；进入平台：`/v2/welcome`。

## 方向与内容

参考 https://www.dshdesktop.cn/ 的深色背景、左文右产品大图、明确行动按钮、分章节讲述用途的方式。会同里采用深墨绿、浅绿、校园实景照片及中文衬线品牌字，建立校园生活的亲近感。主动作是进入现有平台；功能入口连接已存在的活动、社区、同伴和校园探索路由。

页面依次为首屏产品展示、四项功能切换、三个生活场景、全幅校园故事、常见问题与末尾进入按钮。首屏窗口为专门制作的 HTML/CSS 产品展示，说明功能用途，不读取用户个人信息，也没有虚构用户数量、报名结果或学时。校园照片复用项目现有素材，来源记录沿用 `design/campus-photos/sources.json`。三维校园入口连接现有完整校园查看器的宿主页。

## 动效与可访问性

- GSAP 首屏文案错峰出现；下方区块滚动出场。
- 校园故事区照片随滚动由 1.18 倍缩放至 1 倍并上下移动，形成从校园远景到眼前生活的叙事。
- 按钮悬停轻移、功能切换过渡、FAQ 图标旋转。
- 减少动态偏好下移除进场、视差及过渡，保留静态可读内容；动画上下文随卸载清理。
- 功能标签支持方向键、Home、End，FAQ 使用原生 details；提供跳到正文、可见焦点、移动导航与图片替代文字。
