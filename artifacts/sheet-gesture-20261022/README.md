# 面板下拉阻尼验证

- 方向：沿用会同里现有面板与材质，在顶部增加轻量拖动提示；拖动只发生在标题区域，保留正文滚动、输入与按钮点击。
- 范围：StudentUtilityPanel 共用的设置、会话/通知、组队筛选、发起组队；通用 Modal 通过 gesture 参数按需启用。
- 位移：正向原始距离 d 映射为 d/(1+d/600)，拖得越远阻力越大；小于 6px 不启动，横向动作不接管。鼠标和触屏走相同 Pointer Events，并捕获指针。
- 松手：距离达到 clamp(面板高度×22%,96px,160px)，或者至少拉动 32px 且末段向下速度达到 0.65px/ms 时关闭；停留超过 100ms 后松手不沿用旧速度。其他情况按弹簧回到原位。取消手势或窗口失焦回弹；再次拖动可从当前回弹位置接续。
- 背景：只在拖动/回弹/关闭期间，轻微改变遮罩透明度与 0–3px 背景模糊；静止时恢复原本无背景采样的稳定材质，避免重新引入设置滚动时的持续叠层采样。
- 减少动态效果：保留相同拖动关闭判断，取消跟手位移、模糊与回弹动画。关闭按钮、遮罩和 Escape 仍可使用。
- 实测：本地浏览器顶部短拉三次保持面板，长拉关闭三次；正文滚动到约 504px 时标题位置不变，短拉回弹后保留正文位置；关闭恢复页面滚动与 inert 状态、返回入口焦点。筛选面板长拉关闭；发布面板短拉保留、Escape 关闭；减少动态设置实际切换检查后恢复原值。详见 checks.json。
- 4 项单元测试覆盖递增阻力、误触/反向速度、快速甩动与距离关闭、不同高度阈值。类型检查与 ESLint 通过。
- 自查：顶部提示与标题、关闭按钮无重叠；仅进行本地浏览器鼠标指针验收，真实手机触摸、pointercancel 和窗口失焦回弹未做设备验收。速度分支由单元测试验证。
