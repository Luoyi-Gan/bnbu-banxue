# 手势驱动面板 · 2026-10-22

保留现有地图地点卡片、共用详情阅读 UI，手机端增加顶部把手；桌面隐藏把手并沿用现有布局。

## 行为

- 校园地图地点面板：只在把手上捕获指针，拖动实时改变高度；释放按高度和速度短程投影选择紧凑/中间/展开三档。速度做平滑、上限和停顿衰减，超过上下边界有阻尼。点击/键盘激活把手也可循环高度。
- 活动/帖子/搭子共用详情：短距离下拉弹簧回弹；达到距离或下甩速度门槛后调用原关闭路径。手势关闭直接从当前位移进入既有共享返回，不先飞出屏幕再复位。
- 正文和地图本身不捕获拖动；保留原滚动、输入和地图操作。取消/失去指针捕获/窗口失焦时回到起点，窗口尺寸变化及卸载清理临时样式和动画。减少动态时不跟随大幅移动，释放后直接完成吸附或关闭。

## 本地验证

393×852、深色、模拟学生；最终恢复正常动态与原视口，预览留在活动页。

- 详情短拖20px：释放时 offset19.35484、state settling，之后offset0/top0/state空。
- 在正文内滚动：reader.scrollTop260、window.scrollY0、面板offset0，滚动不触发拖拽。
- 正文滚动后长拖217px关闭：详情卸载、body overflow恢复空、共享返回complete。
- 地点使用实际本地3D校园模型的学习资源中心（一期）卡片。初始高度383.46；向上拖后释放时527.46、最终吸附626；下拖后吸附388.12。内部滚动到265时面板高度和window.scrollY0保持。点击把手从中间档展开到626。
- 1200×800切换：把手display none、临时height清空、手势状态清空；回手机尺寸可继续使用原布局。
- 减少动态详情：短拖offset0、长拖返回direct；地图点击把手直接吸附626、无残留状态。
- 快甩与慢拖的差异、极端速度限幅和边界阻尼由新增决策回归覆盖；本轮原生浏览器drag未精确控制速度，也未注入pointercancel。失焦/取消分支作代码检查，不能视为真机手势验收。
