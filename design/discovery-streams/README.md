# 发现信息瀑布流与页面减法

方向：沿用校园窗口品牌、MiSans、霞鹜文楷和既有照片，把发现变为内容优先的浏览页。手机双列错落排布，桌面按内容宽度扩展至 3–4 列；四类使用同样的频道、搜索、分类、内容顺序。去掉原发现大图、重复快捷入口与精选/全部切换。

## 逐页检查

| 页面 | 处理 |
| --- | --- |
| 首页 | 组织推荐保留“更多”，删重复宣传横幅；校园服务保留自身入口，移除同区重复“更多” |
| 发现 | 活动、社团组织、校园社区、校友交流同页切换，统一瀑布流；管理入口与其中的既有热榜保留 |
| 校园 | 删与下方模块重复的四项快捷入口；课表只保留预览中的完整课表入口；Coffee Chat 保留可点击内容，去掉重复“更多” |
| 社区 | 共用瀑布流卡片，只保留页首发布；删大图与隐藏的宣传侧栏；单卡图片和标题合并为一个阅读动作 |
| 校友 | 保留经验、寻找校友与我的交流；管理页不再链接自身；寻找校友页去掉宣传模块，保留经历来源说明 |
| 个人二级页 | 只保留页首标题；保留操作与说明。队伍和收藏帖子直接进入已有对象详情 |
| 日程、Coffee Chat、找搭子、消息、运动、设置 | 检查当前主要结构与入口；保留浏览、筛选、对象详情、管理及操作各自必要职责 |
| 教师与管理员 | 源码检查：总览指标和对象队列分别承担汇总、处理任务，未将其视作重复功能；未重新做角色登录验收 |

## 卡片与业务边界

- 活动继续显示原时间、地点、主办方、参与标记、本人点赞标记和收藏。打开原详情，不新增活动或报名规则。
- 组织使用记录中的照片；没有照片时以组织字标展示。关注沿用原命令，简介及联系方式可展开读取，原文不改写。
- 社区保留原服务排序、筛选、翻页与详情，点赞/收藏同源保存；浏览数仅按原作者权限显示。只有一处“加载更多”负责追加本批或服务端下一页。
- 校友内容数量取自当前服务，目前预览账号只有一篇可见经验；右侧留白不补造数据，寻找校友和已有交流入口可用。
- 用户内容、权限、数据结构和状态流程沿用；未新增依赖或下载照片。

## 状态、动效与评审

- 分类选中态、筛选展开、加载中、空结果、图片失败及原错误信息均保留。切换面板采用 180ms 轻微淡入，图片加载和选中颜色短过渡；减少动态时关闭。
- 独立视觉评审一轮（存量润色，不打分）。根据反馈统一校友搜索/分类顺序，提高次要文字可读性；重复的模拟组织简介收进展开区，保留用户内容及模拟说明。
- 主 Agent 复查手机与桌面画面、英文大字暗色、卡片元信息和展开的组织资料。最终图片是相应状态截图，部分图会因本地模拟时刻与交互计数变化存在差异。

## 验证

- 本地 4174 前端、4175 API；主要页面入口及标题检查保存在 `page-audit.json`。
- 活动地点选“体育馆”返回对应两项；打开活动原详情、关闭返回发现。社区收藏变更后刷新读回并恢复原状态，帖子详情及讨论可达。校友工具进入已有校友列表。
- 手机 320px、393px和桌面 1440px；英文暗色大字无页面横向溢出；桌面信息流为四列。列表滚动到底后，最后一张卡片的操作完整露出于固定导航上方。
- 类型检查、范围 ESLint 和六个相关测试文件通过，共 37 项。原参考页测试补齐真实 Provider，并将过时的体育展开进度断言改为用户已要求的进度按钮。
- 验证限本机模拟数据；没有执行生产构建、生产发布、真实设备或所有角色全流程验收。
