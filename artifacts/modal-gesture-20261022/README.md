# 共用弹窗手势统一 · 2026-10-22

沿用现有设置、筛选、发起组队、课程编辑和其他共用弹窗 UI。设置与 StudentUtilityPanel 原本已开启旧手势，本轮升级共用实现，并让其他 Modal 默认接入。

## 实现

- 共用 Modal 默认启用手机标题栏拖动；桌面标题栏保持原点击/文字行为。正文不注册拖动事件，按钮、链接、输入、选择器与编辑区不触发标题栏手势。
- 复用原阻尼/距离决策和校园 spring 参数，速度平滑且停顿后不沿用旧速度；允许回弹中从当前位置继续拖动，轻触打断后仍回到原位。
- 仅最上层可见且非 inert 的弹窗处理拖动和 Escape。嵌套弹窗关闭时保留下层；取消/失去指针捕获/失焦时回弹，尺寸切换和卸载清理指针、动画与临时样式。
- 关闭动画完成后维持关闭位置，等实际卸载；原关闭条件拒绝时80ms后自然回弹，避免闪回或把弹窗留在屏幕外。减少动态直接完成结果。
- 共用 Drawer 接入已有专用把手手势；课程抽屉返回动画同时衔接当前 translate，保持缩回原卡片的连续性。
