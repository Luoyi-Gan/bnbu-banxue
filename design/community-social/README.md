# 会同里图文社区 · 2026-10-20

用户确认以当前小红书手机端为参照，保留会同里字体和校园内容，并要求覆盖完整社区机制。本轮实现的是可操作、共用后端的图文社区闭环，界面不使用第三方品牌资产或第三方用户内容。MiSans、校园照片和平台导航沿用现有资源。

## 已接通的机制

| 模块 | 用户路径 | 数据与边界 |
| --- | --- | --- |
| 信息流 | 发现→校园社区；独立校园社区 | 推荐/关注、分区、综合/最新、搜索、滚动接续分页与手动重试；只展示实际可见内容 |
| 图文详情 | 卡片→照片、正文、分区与评论 | 多图按钮/触屏横滑、原图查看、赞藏评及当前数量；作者可见浏览数 |
| 创作 | 红色发布入口→选图→标题正文→分区→发布 | 最多9图，压缩、移除、换序和封面；80字标题/1000字正文沿用既定规则 |
| 编辑与草稿 | 本人笔记选项→编辑；个人主页→草稿箱 | 原版本检查、原ID/互动保留；草稿私有、最多50份、可删除；发布同事务消费，编辑草稿保存回原帖 |
| 个人主页 | 帖子/评论作者→社区主页 | 真实关注、粉丝、获赞与收藏；本人笔记/收藏/赞过、草稿；他人收藏/赞过不公开 |
| 资料 | 社区主页→编辑资料 | 已有头像昵称与新增100字简介；沿用资料预览隐私，不改变学校身份 |
| 社交关系 | 详情/作者主页→关注 | 一份当前关系，关注流联动，取消可重复；屏蔽清除双向关注并限制访问/互动，解除不自动恢复 |
| 评论 | 详情底栏、评论→回复 | 300字、同帖回复、评论赞、本人删除；父评论删除不删除其他人的回复 |
| 分发反馈 | 笔记选项→不感兴趣/屏蔽 | 仅改变本人可见流；个人主页更多→恢复推荐/屏蔽管理 |
| 互动通知 | 互动消息→原通知中心社区分类 | 新增关注、赞藏、评论/回复/评论赞，实际有效状态转换生成，重试不重复 |
| 举报和治理 | 笔记/评论选项→举报；本人更多→我的举报 | 原举报快照、防重复待处理、原管理员处置、下架、结果通知、本人进度 |
| 校园入口 | 主个人页、首页/校园摘要、校友经验 | 删除近期动态；笔记与草稿统一入口，共用帖子卡片与详情，保留校友预约与原关注筛选 |

主预览：`/v2/activities?section=community`。独立社区：`/v2/community`。本人社区：`/v2/community?person=me`。具体笔记使用已有ID的 `?item=`，编辑使用 `?edit=`。

## 业务实现

- `community-social.ts` 为SQLite与PostgreSQL共用策略，新关系/草稿使用原实体表；写入仍经过账号权限、事务、幂等回执和审计。没有新增依赖或独立模拟后端。
- 帖子编辑不会通过更换ID丢失点赞评论，词库拒绝或版本冲突时保持原记录；处置过的隐藏/删除状态无法通过编辑绕过。成功发布原子消费草稿，重复发布同一已消费草稿被拒绝。
- 收藏、赞过、草稿、屏蔽和举报明细仅本人读取；公开主页不提供邮箱、学号、账号角色或他人浏览明细。原资料预览关闭时隐藏其他学生的昵称头像和简介。
- 统计由关系及公开评论计算，实际删除、取消、处置后重新读取。帖子打开仍经原 `post.view` 幂等记录；直接详情路径也支持计数，信息流滚动不增加浏览。
- 新只读元信息查询不携带全部帖子图片/正文；返回帖子、评论、人员及举报按页处理。校友经验先按服务端条件筛选再分页，避免被首20篇普通帖子挤出。
- 重复分页由锁与ID去重处理，查询切换后忽略旧响应；详情请求按序号接收，表单保存失败保留输入。滚动加载一次失败后保留可点击的加载入口。

## 界面与评审

方向为图片优先、双列自然比例卡片、紧凑作者行、红色创作和互动强调；保留校园照片和会同里字体。详情用手机整屏/桌面左图右文，底部操作固定；发布图片网格与添加入口同时可见。小窗口保持焦点，关闭恢复发起处；未保存编辑给草稿/放弃/继续选择。沿用短淡入、控件状态过渡，减少动态时取消过渡。

独立视觉评审一轮，初稿 **7/10**。评审者只看截图和任务，不能验证交互。四项问题已由主Agent修正并复看：

1. 顶部层级占用过多：压缩校园标题/分类间距，草稿入口归入个人主页，首张照片在393px视口约251px处出现。
2. 创作图列滚动条突出且添加入口裁切：改为三列图片网格，保留换序与封面标记。
3. 轮播大白圆按钮抢画面：保留触控范围，缩小半透明背景。
4. 卡片元信息松散：删除信息流重复浏览行，统一标题、作者与点赞间距；浏览数保留在作者详情。

另修正发布后草稿参数残留、门户外按钮强调色变量、嵌套窗口关闭后的背景交互、英文主页标签、深色文字对比及社区主页上课表悬浮入口位置。修正版未另行评分。
