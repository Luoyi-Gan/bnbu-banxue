# 校园 AI 知识索引与聊天交接

2026-10-23。用户要求AI全面获取平台信息，并参考ChatGPT聊天界面。本轮范围为既有学生校园AI；模型仍为已配置的DeepSeek。

## 数据覆盖

| 类别 | 当前来源 | 权限与完整性 |
| --- | --- | --- |
| 办事与联系方式 | campusContacts、已发布knowledge | 保留官方来源、查阅日期、page/index核对层级；目录存在不代表正文核实 |
| 校园地图 | 公开campus-places.json生成的236项具名地点 | 保留名称、用途、楼栋、校区、公开来源，现状待核实；没有个人定位 |
| 社团、活动 | 已批准可见organization、已发布可见activity | 社团完整目录及独立正文；活动参与/收藏仅取本人关系 |
| 探店 | 可见shop及其可见shopReview | 已隐藏/删除店铺及其点评排除；不发送图片原件 |
| 搭子、社区 | 全量room/post/comment目录 | 不受界面50条限制；双向屏蔽、父帖可见性、房间公开/本人成员权限过滤 |
| 课程与待办 | 本人timetable、学校当前会话course名录、有效deadline | 全部课表节次，不截60条；复用课表校历生成未来371天内已核实的已选课程发生项；DDL继续遵守已选课程、未完成及来源归属规则 |
| 教师与校友交流 | 原工作区可见teacherProfile/coffeeSlot、本人coffeeBooking、scoped alumni | 公开交流简介和可约时段、本人预约；身份失效/关闭时段排除，不发送审核证据 |
| 本人通知与偏好 | recipient_id限定的通知、本人profile允许字段、本人关系 | 不查询私信、账号目录、密码、验证码、学校令牌或审计材料 |
| 体育 | 原movementNative及personal.list | 涉及体育时按需实时读取；原本人身份/会话验证，课程进度、分页记录和独立个人运动；不写课程学时 |
| 导航 | 已有平台路由 | 引用回对应页面；不执行报名、预约或发送消息 |

新公共目录读取是权威来源，不从过期/分页的UI快照或旧探店回调补回已删除资料。公开实体只投影白名单内容字段，ownerId、成员名单等不进入模型。本人资料由原工作区权限投影提供。

## 存储与检索

- `campus_ai_chunks`是可重建索引，字段为actor_id、chunk_id、content_hash、data，主键(actor_id,chunk_id)，外键accounts(id) ON DELETE CASCADE。服务端首次使用通过共享LearningStore建立表；PostgreSQL采用全局schema协调锁，然后按账号同步，SQLite使用既有事务队列。
- 每次提问先读取当前许可资料，以900字分段、760字步长保留交叠，正文不截头；NFKC规范化、英文词与中文双字词索引，段落和词项持久化。相同内容哈希不重写，撤回/删除的段落在下一次该账号检索前清除。没有跨账号共享的私有倒排表。
- 对当前账号全部段落建立倒排词频和BM25排序，结合标题、类别及有限同义词扩展。无需外部向量/embedding服务。完整/全部/数量类问题优先相应分类目录；目录证明名称和数量，不代替正文。
- 索引本身不受24条、50条或60节等界面上限影响。单次模型上下文最多40段/26000字；索引全量与上下文选取是两个不同范围。体育历史最多读取20页，未读完标记部分；不能声称无限历史已全部读取。
- 每个回答保存本次覆盖报告：文档、分段、选取数量、类别数量、索引时间、学校/体育连接状态及缺口。`POST /api/ai/knowledge`只返回本人覆盖状态，不返回原文或其他人的分区，不调用模型。
- 地图更新后执行`node scripts/build-ai-map-index.mjs`；单元测试比较源文件SHA256，阻止漏更新AI静态地图索引。

## 会话与界面

- 中央窄幅正文、轻量用户消息、无气泡AI正文、固定多行输入区、桌面低对比度历史栏、手机历史抽屉；聊天页只保留一套导航，保留返回校园入口。
- 新建和搜索独立会话，URL中的chat保留刷新后的当前会话；本人问答按conversationId分组。自动追问上一条回答，最多8轮/10000字祖先上下文，先前事实须由当前检索重核；legacy问答可继续查看。等待期间可以输入下一条草稿；停止按钮阻止默认表单动作，并用独立元素键避免切换为发送后意外重提。
- 请求回执绑定本人、问题、上文和会话，成功重试复用回执。后台依旧单次JSON完成后返回；没有伪装真实流式输出。停止按钮明确为“停止等待”，不承诺撤销服务端模型调用或费用。
- 引用与检索详情默认折叠，点引用展开来源；支持安全Markdown子集、表格、代码复制和回答复制。模型HTML按文字展示，不执行。
- 校园抽屉关闭再打开保留当前会话，展开完整页携带会话及草稿。键盘、IME、失败保留、同标识重试、阅读中不强拉底部和跳到最新沿用原语义。
- 知识库入口和模型说明明确：问题与相关公开/本人资料片段发送至DeepSeek，单独计费。保留校园身份和用户头像，不冒充OpenAI产品。
