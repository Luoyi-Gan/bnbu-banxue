# 图片按场景重新设计

设计北极星：同一座校园，用适合当前内容的画幅讲述；构图各有特点，字体与色彩保持联系。

用户任务：重新设计所有图片展示效果，直接查看实际效果。品类为三种身份共用的校园服务产品，主要任务仍是找安排、浏览活动、交流与办理事项。现有照片与字体保留，业务接口和状态沿用原实现。

## 展示分配

| 场景 | 新的呈现 | 理由 |
| --- | --- | --- |
| 首页 | 横排问候、白边照片、偏移纸底；桌面照片与安排并排 | 照片提供校园氛围，安排清楚可读 |
| 发现 | 无弧角宽幅海报、下沿细色带 | 强调浏览内容的入口 |
| 校园 | 全景裁切、下沿实色标题签 | 展示空间与建筑 |
| 我的 | 轻微倾斜的白边相片、下方留白 | 与身份资料分开，保留封面选择 |
| 活动 | 精选海报、行内相框、首页短票形缩略图 | 适配不同信息密度 |
| 社区 | 平直编辑式图片、多图联系表 | 照片与文字共同阅读 |
| 校友经验 | 白边照片册 | 与活动海报区分 |
| 日程 | 下沿书签切角 | 作为日程旁的次要推荐 |
| Coffee Chat | 横向圆尾场景、紧凑矩形缩略图、详情圆形场景 | 提前看到老师姓名和话题；场景图不充当肖像 |
| 组织入口 | 上沿色带全景 | 与单个活动内容区分 |
| 教师侧栏 | 白边照片条 | 轻量校园提示 |
| 管理员侧栏 | 紧凑带侧标横条 | 保持管理页面信息密度 |
| 账号与欢迎 | 平直照片板、单侧色标；欢迎整幅留边 | 入口与站内图片区分 |
| 海报详情、课表、邮件、运动凭证 | 中性底托、完整显示 | 避免裁掉原图文字与证据 |
| 头像、AI 图标 | 保持圆形身份头像；插画透明留白与轻投影 | 避免把标识变成风景封面 |

## 动效与约束

保留原校园轮播的切换、暂停和减少动态规则。只为可打开内容的活动、校友封面增加桌面悬停 1.025 倍缓慢放大，教师场景轻微移动取景。触屏无需悬停即可操作；减少动态时不放大和移动。没有新增依赖、自动业务动作或图片滤镜。

文字本轮未增加宣传说明，已有文案保持。消除重复的弧角裁切和图片上方竖排问候，改用横排问候与留白。

## 证据与复现

- `capture.py --before`：15 个代表入口的修改前截图；`capture.py`：45 个既有入口在 1440×900、393×852、320×780、720×450 下的几何检查与代表页面截图。
- `before-report.json` / `report.json`：图片样式清单、页面错误、横向溢出。
- `index.html`：实际截图浏览及前后切换，含真实页面入口。
- `image-interaction-report.json`：图片轮播、四种宽度的标题签避让、封面取消、教师与帖子详情、失效图片文字入口，连续 3 次；对比页的页面、设备、前后切换。
- `interaction-report.json`：既有主页面、二级页面（连续 3 次）、教师和管理员交互检查；`homepage-interaction-report.json`：首页安排入口、保存后刷新、写入失败与恢复、减少动态等 11 项。
- `overlays.json` 与 `popup-*.png`：11 种既有弹层的桌面与手机截图，打开并取消，没有提交业务决定。
- `review.md`：一轮独立存量界面润色评审，无评分；三项提升均落实并由主 Agent 复查。
- `gallery-desktop.png` / `gallery-mobile.png`：实际效果浏览页；`image-treatments.png`：六种代表页面的截图拼图。

类型检查与修改的 TSX 文件 lint 通过。脚本首次运行时修正了 UTF-8 读取和减少动态断言的格式假设；画面检查修正了校园标题在 720px 宽度时被课表遮挡的问题。最终结果以本目录报告为准。

验证仅适用于本地验收账号和模拟数据，不代表生产或真实设备验收。
