# 液态玻璃浮层 · 2026-10-22

采用用户参考的边缘光、背景透色和滚动材质反馈，沿用当前校园配色、字号与控件位置。

## 实现

- liquidGlass.css统一底部导航、搜索框/结果面板、活动筛选浮层、弹窗的高光、内边缘、色彩透射和近远阴影。通过径向高光、轻微背景对比和饱和度模拟折光感；没有对内容像素做位移折射。
- 导航保持较高透明度，搜索结果和大面板使用更厚底色确保可读。搜索打开时移除父级顶部栏的重复背景采样，避免底图文字透进结果。
- 沿用useStudentScrollGlass的被动监听与RAF，每帧最多一次更新。页面与浮层自身滚动分别写入0–1材质参数，无React逐帧渲染；清理监听、帧及变量。
- 设置/筛选的滚动内容层保留原稳定绘制，固定遮罩采样14px模糊；不对滚动内容重复套模糊。模糊半径不随滚动动画，只有底色与阴影跟随。
- 减少动态时固定材质参数0，保留静态高光。缺少backdrop-filter时回退实体背景。本机系统透明度偏好为减少透明度，按用户明确采用玻璃/透光要求显示本次材质。
