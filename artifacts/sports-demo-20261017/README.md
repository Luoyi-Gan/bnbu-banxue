# 体育前端模拟流程（2026-10-17）

用户要求运动计时、凭证上传与详情在会同里内完成，先跑通模拟前端。入口位于 /v2/sports 的“开始模拟运动”。

- 选择户外跑步、健身训练、球类运动或游泳；计时支持开始、暂停、继续、结束和二次确认放弃。
- 采用单调时钟差值计时，暂停不累计；关闭弹窗可继续当前运动。
- 结束后选择图片/视频凭证，最多6个、单个30MB；可使用校园图片演示凭证。文件只在浏览器预览，不发网络上传请求。
- 提交需至少一个凭证；800ms模拟提交期间锁定操作，生成一次本地记录。
- 在“本次模拟记录”查看时长、提交时间、待审核模拟状态、凭证预览和运动说明。记录不计入真实学时，刷新或离开页面清除。
- 旧同步记录继续如实显示摘要，未提供的附件不伪造。页面不再包含体育平台跳转链接。

后续接入：替换模拟提交为运动会话/凭证接口前，处理身份、课程许可、持久化恢复、幂等提交、文件断点续传与学时核算。当前未实现真实运动采集/GPS、服务端上传、真实审核或跨页面草稿保存。

验证：lint、build通过；demoSportsModel、reference、sports-companion共16项通过。浏览器已跑通演示凭证完整链路，检查无凭证错误与暂停状态。文件格式/大小有单元测试；实际文件选择与视频播放在真实设备上仍需验证。
