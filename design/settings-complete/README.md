# 设置、双语显示与个人页入口归并

## 方向与交互

延续校园窗口的暖白、蓝灰、MiSans 和霞鹜文楷；设置按实际任务分组，以单列列表和独立详情页承载选项。英语使用现有 MiSans，缩短常用标签，允许标题及说明自然换行。照片沿用原素材。主题、语言、大字与校园显示偏好即时应用，当前浏览器保存失败时提示并保留旧值。

“我的”统计区承载活动、关注组织、队伍和收藏。删除重复的四项快捷图标，以及底部活动、组队、收藏、日历和设置项；右上角进入设置，日历保留原日历模块，底部只保留课表、校友交流和认证。近期动态直接打开对应对象，不再额外提供重复活动总入口。

减少动态关闭界面过渡与照片自动播放，手动切换仍可用。弹窗沿用原动效并补焦点循环和关闭后恢复；本轮入口归并没有新增动画。

## 范围与约束

- UI 文案在源组件的展示边界翻译，模板参数保留用户内容；HTML option 的业务值显式保持原值。姓名、课程、帖子、活动标题与建筑名称保留原文。
- 体育及完整地图通过同源、校验来源的消息接收偏好；导入的独立地图仅转换已知控件，跳过地点数据、标注与输入值。
- 用户提供运营主体“珠海澄序智能科技有限公司”和邮箱 `siltotchen@gmail.com`。隐私政策可在登录前访问；数据区域、服务商与保存期限明确待确认。
- 没有添加缺少后端支持的账号注销功能。教师与管理员的界面接入相同显示层，保留各自权限与操作。
