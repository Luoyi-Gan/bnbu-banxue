# App Store 特点分析与会同里局部细化

目标：保留会同里的校园风格、布局、字体和业务结构，借鉴短促反馈、克制层次、稳定空间关系。

## 来源与证据边界

使用用户指定的 REA 本地逆向分析插件，以临时 Edge 进程运行 App Store 网页版 Today 场景（393×852）。页面成功加载；点击首张故事后显示 `An Error Occurred`，未取得有效故事展开效果。临时浏览器进程已由 REA 终止。

- [App Store Today](https://apps.apple.com/us/iphone/today)：图片主导卡片，轻阴影、清楚的标题层次。
- REA 返回的样式资源 `https://apps.apple.com/assets/index~DPWTyaYqK4.css`，387554 bytes，SHA-256 `c22b32431156c59c483754a831319c59ca6ad8c0ee25fb493540859586bce7b0`。
- `.get-button` 按下背景反馈 .14s，hover .21s；`--shadow-small:0 3px 9px #00000014`；大圆角变量17px。保留证据片段、捕获步骤与DOM/截图摘要见 rea-evidence.json。网络内容保留不完整，不能据此声称完整逆向。
- [Apple Motion 指南](https://developer.apple.com/design/human-interface-guidelines/motion)：有目的、短促、可选的动效，与实际操作对应。
- [Apple Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles/)：一致反馈与明确层级。

以上为网页运行证据与官方设计指导。没有取得 iOS 原生 App Store 二进制、原生弹簧参数、手势轨迹或真机帧率。会同里的缩放幅度及释放节奏是本地设计选择。

## 采用方式

| 特点 | 会同里的细化 |
| --- | --- |
| 短促的操作反馈 | 卡片按下缩至.985，主要按钮.97，按下140ms、释放210ms；保留现有图标和品牌色 |
| 内容优先、轻量分层 | 封面增加轻阴影；阅读内容滚动后顶部才出现边界，回到顶部消退 |
| 稳定空间关系 | 保留原共享转场，并用稳定滚动条占位避免锁定页面时底层信息流宽度改变 |
| 输入与无障碍适配 | 键盘焦点边界、触控设备避免悬停抬升残留；减少动态时关闭新增缩放和过渡 |

新增样式仅作用于学生端及其阅读浮层，未改导航结构、页面信息架构、接口或业务操作。

最终个人页检查发现深色日历选中日期沿用暗色数字，已改用现有品牌浅绿与12%选中底色，提高辨识度。

## 本地检查

- 393×852、393×700手机视口，深/浅色阅读，1200×600桌面正文独立滚动；查看保存截图。
- 同一帖子封面在打开前、详情打开后、返回后均为 x=15.997px、width=167.290px；底层卡片未因滚动锁定而跳位。
- 阅读滚动后顶部轻阴影生效，回到顶部清除。RAF合并滚动更新，卸载取消待执行帧。
- 减少动态时卡片计算样式 transition none、scale 1，共享导航 reduced/direct。
- 类型检查、ESLint、6项已有针对性共享/图片回归通过。按压规则已接入并核对计算节奏；未录制触屏按压过程或测真实设备帧率，未作独立视觉评审。
- 原深色/正常动态偏好与临时浏览器尺寸已恢复。截图和运行状态见当前目录及 ui-audit.json。
