## 当前实现

学生首页、接通版首页及学生体育页复用紧凑进度卡：圆环、确认小时／目标小时、剩余小时、课程和进入打卡。只有匹配体育身份且当前学期有效课程存在确认进度时显示。加载中、无体育身份、无确认投影及读取失败时不显示卡片；确认零值仍显示。截图中的 10.5 小时只用于独立布局样例和单元测试，未写入业务库。

`/api/workspace` 返回本人体育摘要。当前两套本地功能共用账号表，以服务端已登录个人账号 ID 和规范化邮箱核对体育身份；不按任意客户端邮箱查询。独立管理员同邮箱、浏览器角色与本地演示资格不能充当匹配。首次改密、封禁和维护不返回正常摘要；只返回进度卡所需字段，不返回成绩、原始材料或其他账号的进度。首页 30 秒轮询并在窗口聚焦时更新。

教师入口和日程、消息页中的体育链接改用服务端匹配结果。无本人已核验体育教师身份则隐藏入口，直接打开 `/v2/teacher/sports` 返回教师首页。有资格者在教师体育页与 `/workspace/sports` 查看同一可视化组件。学生入口移除自动 `preview=student`，不通过预览数字填充账号数据。

教师看板沿用蓝白色、卡片和侧栏：运动横幅、课程／成员／确认分钟／待处理指标、7／30 天提交趋势、状态环图、课程搜索筛选、每日明细、CSV 导出。已有 `/api/sports/workspace` 限定本人课程权限，图表使用相同范围。未授权或无投影显示“—”，不伪称零；按最新服务端确认投影计算；趋势依据提交日期和北京时间，提交不等于已计入。刷新失败清空旧统计，旧响应不覆盖新请求。原业务状态和权限不变。

## 数据来源与后续接入

当前数据明确来自本地体育库，线上同步按用户决定留到后续配置。指定线上站点 `https://www.teacher.bnbusports.cn/#admin/` 读取超时，未取得线上数据；没有复制网站凭据或修改线上记录。体育平台跳转尊重 `VITE_SPORTS_TEACHER_URL`，无配置沿用原线上快捷入口。后续只读接口或数据库连接确定后，须在服务端按已登录邮箱匹配受授权记录，不能将网页登录状态当作跨系统连接。
