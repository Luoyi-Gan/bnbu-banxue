# BNBU Sports 原版打卡界面接入

- `/v2/sports` 直接嵌入项目自带 `public/student/js/screens/checkin.js`，复用原始计时、暂停、滑动结束、凭证队列、记录列表和详情；原模块文件保持原样。
- 独立适配文件：`public/student/js/huitongli-checkin.js`，主题：`public/student/css/huitongli-checkin.css`。React 容器监听同源、指定 frame 的尺寸消息，避免移动端双层滚动。
- 会同里暖白背景、绿色按钮、霞鹜文楷标题、MiSans 正文。完整原界面在本应用内部呈现。
- 明确模拟模式，API 模式固定关闭。CSP 的 connect-src 仅允许 blob，本模块无法向 HTTP API 写入。原体育登录会话不被改写。
- 独立模拟身份 HUITONGLI-SPORTS-DEMO-V1，运动草稿使用原版浏览器存储；已提交的模拟记录与凭证保存在独立 localStorage，最多 20 条。浏览器空间不足时保留草稿并提示失败。模拟记录不进入学期进度。
- 30 分钟门槛和 120 分钟上限为模拟课程规则。增加 30 分钟按钮仅用于演示快进。示例图片在当前页面可用，提交后随记录保留；本机文件草稿由原 IndexedDB 模块恢复。
- 后续迁移：替换模拟适配器的身份、数据读取与提交接线；沿用原 checkin 模块和会同里主题。需要独立验证正式接口、媒体上传和真机摄像头。
