# 共享元素转场

用户任务：让卡片到详情保持图片的位置与尺度连续，保留会同里现有页面和业务操作。

实施：

- 活动：发现页和首页推荐卡片图片展开到详情，关闭时收回。标题入口共用该卡图片。
- 社团：公开社团封面/标题进入只读介绍详情；显示原介绍和联系文字，关注复用原接口。
- 教师预约：原校园场景图片从老师列表衔接预约时段页，返回列表反向衔接。
- 个人资料：主页封面衔接编辑页封面，取消时返回；不触发保存。
- 课程：保留既有卡片到Drawer缩放，统一300ms展开/220ms收回及曲线。

机制与边界：一次只命名当前图片。用原生View Transitions测量和投影，图片圆角单独连续变化，避免新旧快照叠影。动画结束清理内联命名，反向回到原滚动及触发焦点。等待已授权数据最多180ms；无匹配图片或浏览器不支持时自然显示内容。系统或应用减少动态时跳过位移。没有新增依赖。
