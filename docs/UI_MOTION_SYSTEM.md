# 会同里移动端材质与动效

2026-10-22：在现有学生端组件上统一参数，保持页面布局、字体、图片、接口与业务流程。

## 参数入口

- `src/v2/motionTokens.ts`：按压 110ms、释放 200ms、错峰间隔 32ms；选择、布局、抽屉与滚动分别复用弹簧。共享图片展开/返回沿用 420/340ms 的既有实现。
- `src/v2/materialTokens.css`：浮层圆角 22px、选中背景圆角 19px、玻璃模糊 18px、饱和度 118%、接触阴影与悬浮阴影、明暗主题边缘高光。组件原有尺寸和图片裁剪继续由各自样式管理。
- `studentGlass.css`、`liquidGlass.css`、`surfaceRefinements.css`：固定模糊半径，滚动只轻微改变透明度及浮动位移；删除导航和顶部栏伪元素的重复模糊。设置、筛选、组队弹窗由固定遮罩采样一次，内部面板不再重复采样。

## 交互规则

| 对象 | 连续性与性能处理 | 减少动态 |
| --- | --- | --- |
| 底部导航 | 一个持续存在的位置弹簧，快速切换重定向现有弹簧；轻微速度形变 | 直接定位、取消形变 |
| 内容卡片 | 统一按压与释放反馈；照片使用接触与远场两层轻阴影 | 取消缩放 |
| 筛选后的列表与课表 | 复用 Motion 位置投影，布局采用同一弹簧；新卡片只入场一次 | 直接布局 |
| 通用弹窗 | 标题区捕获拖动，正文保留原生滚动；松手速度从 px/ms 转成 px/s，并按阻尼曲线映射，限制极端速度；中断时保留当前位置 | 直接回位或关闭 |
| 地图抽屉 | 专用手柄控制高度，速度参与档位选择和吸附弹簧；ResizeObserver 的地图通知合并为每帧最多一次 | 直接吸附 |
| 图片详情 | 复用既有源图/目标图命名和返回定位；展开后的稳定标记防止入场动画重播 | 直接打开/返回 |

共享图片转场仍由浏览器 View Transition 完成，快速请求由现有机制合并到最新意图；没有把这种定时快照动画描述为可以在任意帧继承速度的物理弹簧。地图抽屉因真实可滚动高度需要调整尺寸，仍有局部布局成本；其他主要位移采用 transform/translate/opacity。

## 本地验证

对比与记录见 `artifacts/mobile-material-system-20261022/README.md`。通过 393×852 浏览器检查，另检查 1200×800 桌面导航隐藏、深色筛选、减少动态、连续详情打开返回、短拖回弹和长拖关闭。检查结束恢复原有“跟随系统”主题和正常动态，重置临时视口。

6 个相关测试文件共 34 项通过，覆盖共享图返回和快速请求、照片连续性、列表入场历史、状态反馈、弹窗取消/卸载/嵌套/关闭保护及释放速度。TypeScript 与针对改动文件的 ESLint 通过。

标准 `npm run build` 两次在 esbuild 删除临时文件时遇到 Windows `Access is denied`（更换临时目录仍复现）；没有将其记为构建通过。补充 `vite build --target esnext --minify false` 模块打包通过（2334 模块），此检查不能代替默认目标的压缩构建。

这是本地模拟数据和浏览器验证；没有真机帧时间或触摸延迟测量，不据此承诺特定帧率。无新增依赖。
