# 会同里体育记录与凭证界面交接

## 本次变化

学生 `/v2/sports` 接入项目自带的 BNBU Sports 打卡界面，复用原版开始、暂停、滑动结束、凭证与详情操作，并以独立样式适配会同里。记录列表按日期分组、支持课程/自主筛选；详情突出实际运动时长，单独呈现计入学时；凭证表单提供照片/视频选择卡片、示例凭证、说明校验和模拟保存反馈。

主分支原体育页为空白，本 PR 同时包含本次界面所必需的体育容器、进度卡和本机模拟适配器。其他尚未合并的首页、发现、社区和品牌改造不纳入。

## 模拟与迁移边界

- 原始 public/student/js/screens/checkin.js 及体育 API 保持原样；新增 huitongli-checkin.js、huitongli-presentation.js 和主题 CSS。
- API 模式固定关闭，内容安全策略只允许 blob 网络连接；模拟凭证不发送到体育平台。
- 模拟身份、记录存储独立于体育登录；最多保留 20 条浏览器模拟记录。存储空间不足时提示失败，不宣称提交成功。
- 示例课程与记录含示例图片。真实进度仍读取现有授权数据，不可用时保留占位。
- 计时、文件草稿沿用原本机存储；示例凭证提交前仅存于当前页面。真实摄像头、视频转码与正式上传仍需迁移阶段真机验收。
- 字体随前端提供：MiSans Regular、霞鹜文楷 Medium；各自许可随文件保留。

## 验证

- 393px / 320px 手机记录列表、详情与凭证区检查，详情无横向溢出。
- 浏览器走通开始、快进、暂停、结束、添加示例凭证、缺少说明校验、填写说明、保存、列表与详情预览；刷新后记录保留。
- 独立 origin/main 工作树构建及 lint；体育相关测试 13 项。
- 本地演示不等同于正式体育平台、云环境或真实设备验收。
