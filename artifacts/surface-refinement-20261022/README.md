# 表面、光感与几何细化

| 参考项 | 本次实施 |
| --- | --- |
| 01 定向边缘光 | 保留顶亮底暗，补充左亮右暗；浅色导航左右实际透明度约0.72/0.14，深色单独使用低亮边缘 |
| 02 双层边缘 | 课表胶囊、搜索工具以1px外沿配合顶部/左侧内高光；地图修改专属campus-window.css宿主样式，不修改模型或引擎 |
| 03 渐变模糊 | 顶部固定栏采用带纵向遮罩的附加模糊层；底部导航仅边缘附加采样，中心保持清楚，正文和设置滚动面不增加嵌套模糊 |
| 04 双尺度阴影 | 首页课程外壳使用近层1px/3px轻阴影和远层14px/34px柔阴影，课表胶囊与搜索工具采用相同关系 |
| 05 表面色温 | 暖色页面基底、较中性的实体卡和浅青玻璃令牌区分；不修改文字与课程类别的语义颜色 |
| 06 光学微调 | 箭头水平0.5px、顶部工具图标垂直-0.25px，课程时间/日期使用等宽数字；属于局部视觉自查，未进行逐图标光学校准 |
| 07 连续曲率 | 原有圆角尺寸上渐进启用corner-shape:squircle，当前浏览器支持并计算为superellipse(2)，不支持时保留border-radius |
| 08 照片协调 | 内置校园照片使用saturate(.97)/contrast(1.01)轻微显示修正，列表和阅读详情一致；个人上传封面保留原显示，不进行逐张色卡校准 |
| 09 分尺度纹理 | 页面采用极低透明度大范围颜色变化；阅读纸面使用128px静态SVG微粒，alpha .025；玻璃面不加同样噪点 |
| 10 图像边缘消隐 | 首页与校园首屏统一向下，在图像80%至100%区间渐隐，不裁切文字 |
| 11 微凹陷 | 星期、日期、通知及发现筛选的选中态加入弱内阴影，未选中保持平面 |
| 12 时段光感 | 首页按上海时间分morning/day/evening/night，使用极低透明度径向环境色；沿用原30秒刷新，凌晨问候同步为晚上好，不切换用户主题 |

- 实际浏览器检查校园、首页、设置深色、活动阅读面、完整校园地图；截图campus.png/home.png/settings-dark.png/map.png，计算样式见checks.json。检查过程发现旧规则覆盖部分阴影/边缘/渐隐，最终记录homeFinal、campusFinal为修正后的结果。
- 深色设置面仍为实体渐变，无背景模糊；左右边缘分别约0.19/0.27。测试后通过界面恢复“跟随系统”，当前解析为浅色。
- 阅读面实际加载静态纸纹，背景模糊为none，内置照片校正与列表一致。地图搜索双层边缘位于查看器专属宿主样式，查看器几何、路线和地图数据没有修改。
- 首页真实时段为night，实际环境渐变alpha .055；课程近远两层阴影均生效。图片最终计算样式确认80%开始渐隐。2项时段边界/异常值测试、类型检查与ESLint通过。
- 局部视觉自查完成，无独立视觉评审；尚未真实手机验收，实际视效随浏览器渲染和设备变化。
