# 发现内容详情 · 2026-10-20

本轮将活动、社区帖子与校友经验详情延续为图片优先的阅读界面。手机用整幅照片连接正文，桌面左图右文；底部保留互动，使长内容阅读时仍能找到操作。沿用已有暖白、深色文字、蓝绿强调色、MiSans字体和校园照片，不新增依赖。

## 页面与真实路径

| 入口 | 阅读内容 | 原有操作 |
| --- | --- | --- |
| `/v2/activities` 活动卡片 | 主办方、照片、时间地点与活动介绍 | 点赞、收藏、参与标记、校园地图、本人展示管理 |
| `/v2/activities?section=community` 帖子卡片 | 作者、原图片、正文、原评论 | 点赞、收藏、评论、本人删除确认 |
| `/v2/activities?section=alumni` 经验卡片 | 校友作者、经验与评论 | 原帖子互动、校友交流时段链接 |

社区与校友经验共用 `CommunityPostDetail`，也覆盖其已有独立列表入口。未修改接口、权限、用户内容或数据模型。参与标记仍不占名额；浏览计数沿用原读取行为，仅作者可见。评论300字上限、可见性筛选、作者删除两次确认和异步失败反馈保留。

## 展示与交互

- `DiscoveryDetail` 提供手机全屏、桌面阅读窗口；背景滚动锁定，背景应用暂时 inert，Escape关闭，Tab首尾循环；关闭时恢复原焦点。
- 桌面活动封面裁切填满左侧，手机展示自然比例。帖子图片完整呈现，保留原手动切换、计数与加载失败文案；无图内容使用单栏正文。
- 活动主办方移到顶部，来源只显示一次；时间同日只写一个日期，跨日显示两端，使用上海时区。地图与本人管理操作折叠，地图展开时加载。
- 评论区只写“评论”和数量，空时给出自然提示。评论输入为空禁用提交，文字输入后启用；点赞和收藏沿用原状态。
- 约200ms淡入/轻移，减少动态时取消。沿用已有英文、深色、大字偏好与安全区。

## 独立视觉评审

一轮存量界面润色评审，不打分。隔离上下文的评审者只看当前截图和约束，提出四项修正：

1. 桌面活动图片留白过大：改为桌面裁切填充，手机保持原比例。
2. 活动同日日期重复且结束时间孤立：合并成单日期时间段，新增跨上海午夜的定向测试。
3. “条已展示”像内部文案，零评论区域空白：改为数量及空评论提示。
4. 辅助信息偏小：日期、作者、评论时间等提升至13px。

主Agent已复看修正后的活动桌面、社区手机、校友手机与桌面截图。另检查320px英文深色大字，修正校友交流链接的英文插值与窄屏评论占位文案。
