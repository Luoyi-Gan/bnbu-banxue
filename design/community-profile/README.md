# 社区个人主页 · 会同里

2026-10-20

设计方向：校园照片建立个人主页的氛围，头像、简介和关系数据紧凑排列，关注与私信并排；下方直接浏览笔记。保留 MiSans 与文楷，社区强调色使用青绿色 `#356f73` 和浅灰绿。通用校园封面不表示用户上传；未设置头像时显示姓名首字，有头像时读取统一资料。

本轮完善：可点击头像预览、校园背景、关注和粉丝列表切换、本人列表项隐藏关注动作、关注人数同步、个人文字私信、会话页的私信列表。他人主页移除属于当前用户的“互动消息”捷径。发布、点赞、关注、分区和焦点颜色统一为会同里色系，保留错误与删除操作的语义提示。

交互：按钮按下时轻微缩放与背景过渡；沿用现有弹窗和列表切换。减少动态时停止过渡。加载列表时保留主页资料，避免切换列表导致头像和封面闪失。私信发送失败保留草稿，发送中加锁，消息由服务端保存，不模拟对方回复或已读。

本地验证：

- 前端和服务端 TypeScript、变更 TS/TSX 文件 ESLint 通过。
- 社区相关测试连续三次通过，最终一轮两个测试文件共 21 项通过。新增私信参与者隔离、管理员无正文权限、请求幂等、屏蔽、身份状态、频率限制测试，并验证同一策略可在异步存储适配器执行。
- 浏览器关注后粉丝数增加，粉丝列表显示实际关系，关注页空态正常；测试后恢复关注前状态。
- 头像预览打开、关闭和焦点返回正常；列表切换保持主页内容。
- 从主页发送一条本地测试私信，刷新仍可读；“我的会话”有对应私信入口。
- 390×844、320×740、1280×900 检查布局；320 视口内容宽 305、1280 视口内容宽 1265，无横向溢出。检查英文和英文深色窄屏，最后恢复原语言、主题及自然视口。
- 一轮主 Agent 视觉自检，无独立评审；未验证物理手机软键盘、200% 浏览器缩放、真实用户和生产环境。私信本轮为文字，不包含图片、语音、已读回执或推送服务。
