# 学习功能接入方案

状态：入口与数据范围已确认，尚未实施。2026-10-22 用户将社区导航优化调整为当前优先项。

参考任务：`01a162bb-a6c5-74b1-988e-061bcedec9aa`，已读取其完整分析。借鉴功能和交互思路，独立实现；不直接混入 BNBU ME 的 GPL 源码。

| 功能 | 现有入口中的位置 |
| --- | --- |
| DDL 与课前提醒 | 我的课表中的学习工具；课程详情展示关联 DDL，首页展示临近事项，提醒汇入现有消息 |
| 课程资料夹 | 我的课表 → 课程资料；课程详情可直接查看该课程资料 |
| 课件阅读与随页检索 | 资料夹 → 文件阅读器，保留页码、笔记和返回资料夹的导航 |
| 个人重复安排 | 我的课表中的个人安排；并入首页下一项安排，不恢复独立“我的安排”页面 |
| 校园办事与公开联系方式 | 校园 → 办事与联系方式，同时接入现有顶部搜索 |
| 考试安排与成绩 | 我的 → 考试与成绩，按学期查看本人的个人记录 |

用户已明确选择：

1. 考试与成绩先支持本人手动录入和导入，明确标注个人记录。
2. 课件先做本机阅读、笔记与原文检索，不调用外部模型。不能将原文匹配结果描述为模型理解、公式解释或完整 AI 问答。

实施约束：个人课件、成绩、DDL 和安排只向本人提供；SQLite / PostgreSQL 使用同一业务约束，版本冲突和账号状态继续校验；私有文件沿用经过鉴权的私有对象存储，不生成公开下载链接。重复安排与课程周次遵守现有校历，不推断正式选课、到课或学校成绩；不自行计算并冒充官方 GPA。办事资料需有可核实的官方来源与维护入口，公开目录搜索不扩大现有学生学号查询权限。

后续实施需同步 BUSINESS_RULES、权限与导入边界测试、ADMIN_COMPLETION 和真实浏览器验证。网页关闭后的系统提醒能力需明确实现渠道及限制，不能用前台定时器冒充后台推送。
