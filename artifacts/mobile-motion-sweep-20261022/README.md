# 手机端转场交接与弹窗巡检

保持现有布局、圆角、字体和业务操作，优先修复活动展开完成时的闪烁，并补查常用学生页面/浮层。

## 活动闪烁的原因与修复

修复前实际采样：共享转场期间详情 animation 为 none；临时根标记清除后，CSS 的 note-detail-enter 又被启动。采样记录到 opacity 0.960361、纵向偏移 1.01928px，随后恢复。这对应用户看到的结束时闪烁抖动。

现在对参与共享展开的目标容器记录其已进入状态，在该容器整个挂载期间持续禁用自身的 CSS 入场动画。共享快照结束和临时状态清理不会再次触发入场。直接进入、无来源及减少动态路径保留原降级行为，不给未参与共享的容器添加标记。

- 原始记录：activity-handoff-before.json、activity-handoff-after.json。
- 修复后连续3次正常展开/关闭、快速双击、浅色活动，以及详情挂载后 Esc 反向关闭检查通过。
- 共享交接结束后的采样均为 opacity 1、transform none、活动面板 top 0、animation none。
- 同机制补查帖子、找搭子、Coffee Chat、探店和个人资料编辑，结束后均未重启容器入场动画。有效场景记录见 handoff-sweep.json；每次正常重入等待上一次交接结束。

## 其他局部优化和检查

- 弹窗关闭、搜索关闭、顶部工具、组队分类与筛选摘要沿用140ms按下/210ms释放反馈；设置行采用主题背景反馈，避免压缩整行内容。
- 共用弹窗、阅读/抽屉正文、工具内容与搜索结果使用纵向 overscroll contain，保留原生滚动，设置12px内部滚动安全距离。
- 笔记选项叠加弹窗、搭子筛选、长组队表单、设置和搜索浮层实际打开/关闭。筛选滚动约119px、设置817px、长表单896px时，背景页面均保持scrollY 0；底部操作可达。
- 补访首页、运动、消息、校友页面；无共享命名残留，离开弹窗后滚动锁定正常释放。未执行发布、报名、预约、发送、关注等业务提交。
- 减少动态时活动direct、关闭按钮scale 1/transition none。验证后恢复深色、正常动态及原浏览器视口，留在活动列表。
