# 参考图页面重构 · 2026-10-17

## 页面与实现

本轮用户授权完全依照六张参考图重构。独立组件位于 `src/v2/reference/`，已在当前工作区接入。

| 页面 | 地址 | 主要布局 |
| --- | --- | --- |
| 启动页 | `/v2/welcome`（根入口跳转） | 全屏校园照片、品牌与开始探索 |
| 首页 | `/v2` | 校园轮播、今日概览、近期安排、活动、动态、组织、服务、AI |
| 发现 | `/v2/activities` | 搜索、图片、快捷入口、分类、时间地点排序、卡片与列表 |
| 校园 | `/v2/campus` | 本人课程摘要、组织、社区、搭子、Coffee Chat、服务 |
| 打卡 | `/v2/sports` | 校园图片、环形学时进度、记录与同步 |
| 我的 | `/v2/me` | 个人封面、统计、快捷入口、近期动态、周日历、功能列表 |

既有详情、资料编辑、课表导入、认证和活动发布管理仍通过真实路由访问。图片里尚无接口的 GPS 开始运动、校卡、请假、成绩查询未实现为模拟业务。组织使用关注语义，活动沿用参与标记。
