# 设置页优化

2026-10-19，使用 Oil UI 本地增强流程优化现有设置页。

方向：沿用校园窗口字体、暖白和蓝灰配色，用账号入口、分类列表、分类详情组织设置。首页只保留账号、隐私、提醒、资料展示、演示数据及字体许可入口。七个既有偏好沿用原 API、权限和保存方式。

参考：[iPhone 设置](https://support.apple.com/guide/iphone/find-settings-iph079e1fe9d/ios)和 [Notion 账号与偏好](https://www.notion.com/help/account-settings)的设置组织方式；没有复制品牌素材或新增未接入的设置选项。设置数量较少，本轮采用分类列表。

交互：分类使用链接与 section 查询参数，可返回、刷新、直接访问。开关保存时禁用，显示保存状态与错误；关闭态与开启态清晰区分。恢复演示数据仍需原有确认，补充默认聚焦取消、Tab 循环、Escape 关闭和焦点返回。

动效：仅条目悬停底色、开关轨道与圆点短过渡，减少动态时取消过渡。

验证：类型检查、修改文件 ESLint 与差异空白检查通过。实际本地浏览器检查分类入口、七个开关呈现、提醒开关关闭后刷新读回与恢复、恢复确认窗口键盘循环和 Escape。未执行数据重置。实际截图视口为手机宽度；桌面与真机尚未做独立视觉验收。

一轮独立视觉评审后：把含糊的“消息提醒”改为“其他消息提醒”，组队通知独立说明；把入口“个人资料悬浮窗”改为“资料展示内容”；删掉提醒详情重复说明；增强关闭态开关的区分。按现有通知分类实现核对文案。主 Agent 已复查修改后的截图。
