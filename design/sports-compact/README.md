# 运动页：进度清楚，直接开始

日期：2026-10-19。用户指出运动界面杂乱、太长，已有记录按钮却在下方重复铺记录，要求用 Oil UI 优化。

## 方向与范围

北极星：进度一眼看懂，开始运动直接可达，记录集中从一个入口进入。

品类为校园运动工具；用户主要查看学期积累、选择运动并开始，或主动查看记录。延续 MiSans、文楷、暖白与蓝灰；不增加照片或装饰。维持既有接口、数据权限、模拟边界与计时/凭证/保存规则。

## 结构与减法

- 默认页：页首“运动记录”入口、学期进度、既有模拟运动操作。手机上下排列，桌面进度与运动并排。
- 将“完成 16 / 24 小时、还需 8 小时、67%”放进同一概览，保留课程、进度状态和同步。
- 移除重复的英文口号、励志标题、进度说明句、三项记录统计和主页记录预览；学时核算说明保留在概览底部，完整说明仍可打开。
- 记录页分为本机模拟和平台同步。保留本机记录/凭证；平台记录保留状态筛选和详情，直接显示当前完整列表，取消四条预览加“查看全部”的额外层级。
- 压缩本机记录的日期组间距，保持卡片和正文阅读尺寸。
- 运动开始后收起学期概览；计时期间的凭证入口可展开、收起，让暂停/继续保持靠近计时区域。结束确认、凭证选择、运动说明及保存继续由既有模拟器负责。记录导航复用原标签切换处理；iframe 始终保留，避免切换记录来源时重建模拟器。

## 状态与动效

默认 → 记录来源/筛选/详情 → 返回运动；选择运动 → 开始 → 暂停/继续 → 结束 → 凭证与说明 → 模拟保存。保存失败保留凭证与说明，成功可刷新读回。本轮未改变上述业务结果。

保留原运动控件按压、选择反馈、弹层及计时相关动效；同步操作保留旋转反馈，减少动态时停用视觉动画。没有增加页面转场、滚动演出或新库。
