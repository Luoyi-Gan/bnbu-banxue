# 体育看板前端 · 2026-10-12

本 PR 从 GitHub `main` 独立整理，只包含本对话的体育前端、必要路由/只读请求接线、测试和截图。不带本地尚未上传的后端或其他校园模块改动。

## 界面

- `/workspace/sports`：蓝白体育看板，支持学期/课程筛选、7/30 天趋势、状态环图、课程搜索、刷新及 CSV 摘要导出。所有统计来自当前会话有权读取的记录，不用演示数字填充缺失值。
- 学生首页：保留小时进度小卡片，仅在服务端返回本人学生体育进度时显示；无数据隐藏，确认零值可展示。
- 教师体育入口及关联链接：根据服务端体育身份显示。浏览器里的演示资格不作为展示依据。
- 用户已经接受新版，移除“恢复原版”及版本切换。旧查询参数和本机版本偏好不再影响页面。
- 原入口保存在 `src/live/SportsPortalClassic.tsx`；改动前文件另备份于本机 `D:\伴学\archive\sports-ui-before-20261012`。代码恢复不修改数据库。

## 数据服务依赖

此 PR 不实现后端。开发时通过 `BNBU_COMPANION_ORIGIN` 指向另行运行的伴学服务（默认 `http://127.0.0.1:4175`）。生产环境须将以下 GET 路径同源转发到数据服务：

| 路径 | 响应契约 | 用途 |
| --- | --- | --- |
| `/api/workspace` | `account: { id, name, roles }`、可选 `firstLoginOnly`、`sports: null 或 { source: "local", role: "student"/"teacher", progress }` | 当前账号与体育入口显示 |
| `/api/sports/workspace` | `identity`、`serverNow`、`semesters`、`courses`、`enrollments`、`records`、`progress`，可选 `system.mode`/`firstLoginOnly` | 当前账号获授权的课程统计 |

`sports.progress` 类型见 `src/v2/sportsProgress.ts`，包含确认小时、目标小时、剩余小时、完成率、课程、学期、状态和来源；无确认投影必须返回 `null`。课程实体形状及统计字段见 `src/live/sportsDashboardModel.ts`。后端必须在服务端完成已登录个人账号/邮箱匹配和记录隔离；UI 条件不是权限边界，不能以客户端提交的邮箱或角色授予数据。

请求携带同源会话、不缓存。未登录、接口不可用或无有效身份时不展示统计；首页摘要聚焦/可见性变化及 30 秒间隔刷新。无体育账号、没有本人确认进度时隐藏学生卡片，不回退旧预览。当前显示本地来源，未声称已同步线上平台。

体育跳转沿用 `VITE_SPORTS_TEACHER_URL`，未配置时使用原线上快捷入口。学生打卡入口移除自动预览参数。登录和体育操作服务不属于本 PR。
