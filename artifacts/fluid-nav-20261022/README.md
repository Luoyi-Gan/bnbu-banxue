# 液态底部导航

将已有滑动底片细化为位置与材料两层。外层位置使用同一连续spring，内层由实际速度控制横向拉伸、轻微压缩和圆角；接近目标时收拢。再次点击更改弹簧目标，保留当前位置与速度。

颜色和图标大小按底片与每个入口的距离同步变化。减少动态时绘制前直接定位，关闭形变和图标缩放。深色主题复用原颜色，无新增依赖。

验证：

- motion-samples.json为当前应用浏览器原生点击后的真实DOM样式采样。单步移动中scaleX从1上升到1.104，再回落；连续“我的→首页→校园”点击后，目标为校园，底片从约87.7%继续移动到200%，中途scaleX最大1.14，逐渐收拢。
- checks.json覆盖五个入口，均只有一个底片、正确aria-current和选中权重1，最终中心误差0–0.028px，形状恢复scale=1、圆角19px。
- discovery.png、campus-transition.png、final.png为查看过的页面截图；截图本身不代替运动采样。
- 类型检查、lint通过。局部动效由主Agent自查；仅本地模拟账号及当前浏览器验证。
