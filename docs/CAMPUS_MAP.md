# 会同里 3D 校园地图

2026-10-19 将相邻 `BNBU 3D Model` 项目的完整查看器迁入会同里。入口为 `/v2/campus/explore`，活动详情及活动、搭子校内选点共用该查看器。

## 资源与来源

- `public/campus-map/` 保存模型的三个 LOD、材质、环境光、公开地点、周边与矢量地图资源，以及查看器运行文件。资源随普通 Vite 构建进入产物，运行时使用当前 App 的域名。
- `public/campus-map/manifest.json` 记录源仓库提交、导入时间、每个运行文件的大小及 SHA-256。当前导入源为 `1d82bf9c74c3e7e37a761a910f22657f46e04e27`，运行版本为 S1.214。
- 保留 Three.js、pinyin-pro、MapLibre、BNBU-Map、OSM Liberty 的许可文件，及材质 CC0 来源资料。模型中的公开地图来源、照片依据和估算说明继续可见。
- 校园体量和地点信息保留原资料的不确定性，不构成实测尺寸、实时位置或场地使用承诺。

## 接线

`src/v2/campusScene.ts` 管理同源 iframe 的生命周期，并校验消息来源、窗口和楼栋 ID。查看器传回选中楼栋，外层页面继续按当前账号权限读取活动和队伍。离开页面会删除 iframe、监听器和超时定时器。

`src/v2/campusBuildings.json` 与模型同步生成，作为地点名称解析和地图失败后的楼栋列表。两期同名的学习资源中心附加校区，避免保存地点后指向另一栋楼。

原独立地图服务的留言、地点维护、离线安装和服务端验收入口不在本次迁移范围；查看器内部 `/api/` 请求被本地拦截，不会发送到会同里后端。社区及活动等业务仍通过已有接口和权限处理。
