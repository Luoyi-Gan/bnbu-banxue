# 社区导航方案一

2026-10-22，本地模拟页面 `/v2/activities?section=community`。492×952、393×852 浏览器验证。

- “关注 / 推荐”左对齐，间隔 24px；按钮宽度固定，选中文字 18px / 600，未选中 17px / 500，避免切换时布局移动。
- 与下方分类左边界同为约 16px；分类“推荐”显示为“全部”，查询值和筛选逻辑沿用原有“全部”。
- 移除该行头像，搜索靠右，图标 22px、热区 44×44px。
- 独立的 24×3px 绿色指示线复用选择弹簧，快速切换可重定向。减少动态时直接定位。
- 切换栏支持左右滑动、方向键及 Home/End；仅捕获该切换栏，touch-action:pan-y 保留正文纵向滚动。新一次按压会清除前一次拖动的尾随 click 抑制，键盘激活不被抑制。

实际浏览器检查：右滑进入关注，左滑返回推荐；方向键切换同时移动焦点；搜索输入能展开和关闭；减少动态下指示线直接落位；窄屏无横向溢出，深色导航与红色热点榜可读。英语提供较宽按钮与对应指示线步长样式，本轮截图验收为中文。

`before-492.png` 复用上一阶段的红色热点榜截图作为同尺寸基线；`after-492.png`、`after-393.png`、`after-dark.png` 为本轮结果。测试结束恢复系统主题、正常动态并重置临时视口。手势意图的 3 项单元测试、类型检查和改动文件 ESLint 通过。浏览器原生指针拖动不能替代真机触控验收。

本轮仅落地用户最新要求的社区导航。六项学习功能的入口与已确认范围另见 `docs/LEARNING_TOOLS_PLAN.md`，未将该规划记为功能完成。
