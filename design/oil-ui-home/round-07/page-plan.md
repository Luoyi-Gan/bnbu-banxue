# 逐页设计清单

方向：校园窗口。主要任务先于装饰，保留已有字体、校园照片和业务含义。页面入口中的别名继续遵循原路由跳转；本清单不将它们视为新增业务页面。

| 页面入口 | 身份 | 用户任务与布局决定 |
| --- | --- | --- |
| `/v2` | 学生 | 查看下一项安排：保留已确认的校园窗口主卡、照片与摘要 |
| `/v2/activities` | 学生 | 寻找活动：搜索与分类靠近活动卡片，照片建立校园场景 |
| `/v2/campus` | 学生 | 课程与校园服务：照片和课程并列，社区与组织分区 |
| `/v2/me` | 学生 | 查看本人记录：个人摘要后并列近期记录与周日历 |
| `/v2/schedule` | 学生 | 安排今天与本周：桌面日历与安排分栏，手机顺序阅读 |
| `/v2/activities/preview-event-2` | 学生 | 判断活动与参与状态：照片、介绍、事实和操作按顺序呈现 |
| `/v2/activities?view=manage` | 学生 | 浏览与管理活动：保留分类、精选、榜单、筛选及真实对象入口 |
| `/v2/organizations` | 学生 | 认识组织：开放列表、可换行名称与介绍，关注靠近对象 |
| `/v2/community` | 学生 | 阅读与发布：压缩宣传照片，保留一个可见发布入口 |
| `/v2/partners` | 学生 | 寻找队伍：筛选、分类与队伍摘要形成连续阅读 |
| `/v2/partners/teams` | 学生 | 管理已参与队伍：进行中与已完成分开，操作贴近队伍 |
| `/v2/coffee` | 学生 | 选择交流老师：手机首屏显示具体教师与方向 |
| `/v2/alumni` | 学生 | 阅读校友经验：保留现有经验内容与各自搜索 |
| `/v2/alumni?view=people` | 学生 | 寻找校友：介绍与目录分区，保留已关注条件 |
| `/v2/alumni?view=bookings` | 学生 | 查看申请和预约：通知、取消原因与预约记录分组 |
| `/v2/messages` | 学生 | 进入具体会话：桌面列表和消息并列，手机保留返回路径 |
| `/v2/messages?view=notifications` | 学生 | 查看通知：分类与通知列表相邻，状态和对象入口保留 |
| `/v2/settings` | 学生 | 管理个人偏好：隐私设置为主，演示重置放在次级区域 |
| `/v2/ai` | 学生 | 查询校园问题：上下文来源与聊天分工，手机按顺序展示 |
| `/v2/me?tab=profile` | 学生 | 编辑展示资料：限制阅读宽度，区分可编辑与身份事实 |
| `/v2/me?tab=saved` | 学生 | 读取收藏：按对象名称展示，保留直接详情链接 |
| `/v2/me?tab=events` | 学生 | 查看个人活动：保留主办、参与与预约的不同状态 |
| `/v2/me?tab=teams` | 学生 | 查看本人队伍：列表与管理入口对应 |
| `/v2/me?tab=verification` | 学生 | 查看并提交认证：现有状态、申请入口与说明相邻 |
| `/v2/me?tab=network` | 学生 | 查看校园关系：保留筛选和图形结构，画布配色及字体统一 |
| `/v2/me?tab=timetable` | 学生 | 核对课程：按星期切换，课程时间、地点与周次分层 |
| `/v2/campus?service=teaching` | 学生 | 访问个人课表：同一课表组件在服务入口保持一致 |
| `/v2/campus?service=academic` | 学生 | 进入学习社区：保留原有带分区参数的跳转 |
| `/v2/campus/explore` | 学生 | 探索校园：调整内嵌地图工具面板，保持场景与相机逻辑 |
| `/v2/sports` | 学生 | 查看运动与学期进度：保留本机模拟标识、运动入口和真实未知状态 |
| `/v2/teacher/coffee` | 教师 | 处理预约与时段：收紧预约卡片，按钮与对应记录相邻 |
| `/v2/teacher/schedule` | 教师 | 查看本人交流日程：时间与学生信息组成直接入口 |
| `/v2/teacher/messages` | 教师 | 查看业务通知：通知列表或真实空态为主 |
| `/v2/teacher/profile` | 教师 | 维护教师展示资料：约束表单宽度，保留只读资格信息 |
| `/v2/teacher/sports` | 教师 | 查阅体育课程：保留只读统计与数据源错误状态 |
| `/v2/admin` | 管理员 | 进入待办队列：统计用轻量横栏，内容和认证待办为主 |
| `/v2/admin/verifications` | 管理员 | 核验身份：分组保留现有队列、筛选及操作依据 |
| `/v2/admin/moderation` | 管理员 | 查询并处置内容：筛选、列表、详情和原因保持同一阅读链 |
| `/v2/admin/keywords` | 管理员 | 维护词库：桌面编辑区与词库并列，手机顺序展示 |
| `/v2/admin/mail-activities` | 管理员 | 核对识别结果：保留能力提示、上传、手工导入和历史记录 |
| `/v2/welcome` | 账号入口 | 进入校园服务：保留校园照片和单一进入动作，品牌使用文楷 |
| `/v2/login` | 账号入口 | 登录现有账号：照片与登录表单分工，删除照片裁切处的重复英文 |
| `/v2/register` | 账号入口 | 建立账号：保留验证码和密码两步，沿用现有校验与错误提示 |
| `/v2/forgot-password` | 账号入口 | 找回账号：邮箱、验证码与密码阶段沿用原流程 |
| `/v2/identity` | 学生 | 核验校园身份：姓名学号表单或当前状态为主，保留授权依据说明 |
