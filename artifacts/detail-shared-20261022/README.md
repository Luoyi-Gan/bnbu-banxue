# 帖子、校友与找搭子共享转场

方向：从用户点击的照片、头像或插画连续展开，关闭时回到同一对象。正文与操作保留可读尺寸。

## 改动

- 社区、个人主页笔记和校友经验共用帖子封面共享入口与关闭路径。阅读封面使用列表相同的图片裁切，完整照片仍可打开大图。
- 当前照片索引由信息流父组件保留；切换后列表封面和再次展开保持当前照片。图片数量减少时两端选择同一有效图片。
- 找搭子卡片插画和详情复用同一 SVG 内容及深色配色，替换原先把整个抽屉缩放的展开方式。
- 校友资料以列表头像衔接详情头像。活动及 Coffee Chat 保留共用引擎，并复查双向路径。
- 同一对象正在展开时合并重复点击；减少动态设置优先。

## 验证

- 本地合成学生账号、393×852、深色浏览器检查：帖子、校友资料、校友经验、找搭子、活动及 Coffee Chat 打开/关闭均 complete，无活动遮罩或共享命名残留。详见 audit.json。
- 查看帖子返回、搭子展开中间帧；搭子两端背景 rgb(68,62,46)、文字 rgb(209,195,146)、filter none 一致。
- 帖子快速双击、重复进出，帖子和搭子减少动态 direct 通过；偏好及视口恢复。
- 类型检查、全量 ESLint、6 项针对性回归通过，包括多图第二张在列表与详情一致、图片减少后的回退及重复打开合并。
- 多图使用两张合成图片做渲染回归；当前浏览器帖子样本为单图。截图不是等间隔采样，不能据此推断帧率。未作真机性能、浏览器返回手势或独立视觉评审。
