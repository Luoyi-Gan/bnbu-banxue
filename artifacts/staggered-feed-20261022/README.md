# 列表错峰进入验证

- 范围：活动列表、社区瀑布流、社团组织列表。
- 首次进入可视区域的同批卡片按屏幕上到下、左到右排序，延迟从 0ms 起，每张增加 36ms，最多延迟 180ms；透明度 0→1，向上移动 8px，持续 240ms。
- 每张卡片首次进入后停止观察；页面会话内按账号和内容类型记忆已展示 ID，滚动、分页及社团筛选重建不会重播这些卡片。缓存上限为 16 个列表范围、每范围 500 个 ID。
- 减少动态效果、缺少浏览器能力时直接显示内容；键盘聚焦立即显示对应卡片；卸载清理观察器和未完成动画。
- checks.json：实际本地浏览器 DOM 记录，活动滚动与返回、社区重复滚动的 entranceRuns 均保持 1；社团筛选后已见 ID 为 seen，未见内容仍等待首次进入。
- activities.png、community.png、organizations.png：实际本地模拟数据页面截图，检查双列布局及内容显示。静态截图用于展示布局，动画参数与触发记录由代码、DOM 证据及测试共同确认。
- 4 项 Vitest 测试覆盖空间排序与参数、重复观察不重播、跨挂载历史与新增内容、减少动态效果及能力降级；类型检查与 ESLint 通过。
- 自评：沿用现有双列布局与卡片点击范围，移除这些列表外层的整体入场动画以避免叠加；仅本地浏览器验证。
